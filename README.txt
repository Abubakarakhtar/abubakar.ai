ABU BAKAR AI - upload-ready static website

1. Upload index.html to your hosting/server.
2. Open the website.
3. Click ⚙ API.
4. Enter your OpenAI-compatible Chat Completions endpoint, API key and model.
5. Start chatting.

IMPORTANT:
Putting an API key directly in a browser exposes it to the website user. For a public production website, use a small server-side proxy and keep the secret key on the server.
